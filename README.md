## Overview

StreamVault evaluates a candidate list of films for a licensing decision, comparing franchise bundles with standalone titles. The analysis uses publicly available TMDb movie and credits data to build a historical evidence base, shortlist acquisition opportunities, and assess the directors and actors associated with candidate films.

This analysis is decision support—not a forecast of StreamVault's licensing revenue or a valuation of licence prices.

## Project goals

- Compare franchise bundles and standalone films across all available years and from 2000 onward.
- Rank franchise and standalone candidates using consistent criteria.
- Examine director and lead-actor patterns across shortlisted titles.
- Document source-data issues, assumptions, exclusions, and limitations.
- Make the workflow repeatable for future candidate lists.

## Results at a glance

The notebook analysis retained **112 distinct films** from the original candidate list of 127 entries after data checks and duplicate handling.

The analysis indicates:
- Franchise bundles have higher profit per film and median box-office-to-budget multiples in the two comparison windows examined.
- Standalone films have higher average audience ratings in the comparisons.
- Average ROI conclusions vary by time window: standalones lead across all years, while franchises lead from 2000 onward.
- The modern shortlist favours *The Lord of the Rings*, *The Avengers*, and *Harry Potter* among franchises, and *Inception*, *Interstellar*, *Spirited Away*, *The Incredibles*, and *Monsters, Inc.* among standalones.

See the analysis notebook and client memo for the calculations, rankings, caveats, and detailed results. Historical box office minus production budget is not streaming profit and is not a measure of licence value.

## Setup

### 1. Clone the repository

```bash
git clone <repository-url>
cd streamvault
```

### 2. Create and activate a virtual environment

Windows:

```bash
python -m venv .venv
.venv\\Scripts\\activate
```

macOS/Linux:

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Install the project

If the project is configured with `pyproject.toml`:

```bash
pip install -e .
```

If dependencies are not yet declared in the project configuration, install the dependencies listed by the project and then update `pyproject.toml` so a clean setup can install them consistently.

### 4. Configure TMDb credentials

Create a `.env` file in the repository root:

```env

```

Do not commit `.env`. It is excluded through `.gitignore`.

Use `.env.example` as a template. Each person running the project must supply their own TMDb API key.

### 5. Run the analysis

Open the notebook under `notebooks/` in VS Code or Jupyter and run cells from top to bottom. The notebook should load inputs, fetch or load data, perform cleaning, calculate metrics, rank candidates, and produce outputs without requiring manual dataframe edits.

## API key handling

The code should load the key from an environment variable or `.env` file, rather than hardcoding it in notebooks or scripts:

```python
import os
from dotenv import load_dotenv

load_dotenv()

TMDB_API_KEY = os.getenv("TMDB_API_KEY")
if not TMDB_API_KEY:
    raise RuntimeError(
        "TMDB_API_KEY is missing. Create a .env file using .env.example."
    )
```

Add `python-dotenv` as a dependency if this method is used.

## Data and analysis cautions

- Candidate-list records and unique films are not the same: document duplicates and exclusions.
- Films without a valid collection identifier may be classified as standalone under the chosen rule; record that assumption.
- Box-office revenue and production budgets are historical figures and are not inflation-adjusted.
- Box-office profit (revenue minus budget) omits distribution, marketing, financing, and other costs.
- Box-office performance is not streaming performance or licence value.
- TMDb metadata and credits can change over time; retrieval dates and source IDs should be retained.
- The analysis is based on the supplied candidate pool, not a representative sample of all films.
